# Wiki query

Read `wiki/AGENTS.md` if you plan to write back.

1. Read `wiki/index.md`.
2. Open the pages that match the question.
3. Check the cites you rely on: open the file and confirm the line. If a cite is stale, say so.
4. Answer with the cites. Say what you could not confirm.
5. If the answer is new and will matter again, add it to a page, update `wiki/index.md`, and append `## [YYYY-MM-DD] query | <question>` to `wiki/log.md`.
