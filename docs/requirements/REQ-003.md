# REQ-003: Recibos de pago para el inquilino

## Problema y quien lo sufre
Cuando el inquilino paga, el propietario lo anota, pero no puede entregar un comprobante. El inquilino pide un recibo para sus registros y el propietario lo arma a mano en Word o a mano alzada. Esto genera disputas ("yo ya pague") y trabajo repetido.

## Historia de usuario
Como propietario, quiero emitir un recibo de cada pago y enviarlo al inquilino, para tener constancia clara de lo cobrado.

## Valor de negocio
- Menos discusiones sobre si un mes se pago o no.
- Imagen profesional frente al inquilino.
- Ahorra el tiempo de armar recibos a mano cada mes.

## Alcance
Dentro:
- Recibo numerado por cada pago registrado.
- Datos: propietario, inquilino, propiedad, periodo, monto, forma de pago y fecha.
- Descarga como PDF y envio por WhatsApp o email.

Fuera:
- Factura fiscal electronica (ARCA).
- Firma digital.
- Recibos de pagos que nunca se registraron.

## Metrica de exito
- El 90% de los pagos registrados tiene recibo emitido.
- Baja la cantidad de reclamos de "ya pague" a casi cero.

## Supuestos y riesgos
- Supuesto: un recibo simple, no fiscal, alcanza para el propietario chico.
- Riesgo: algunos usuarios esperan que sea un documento con validez fiscal.

## Preguntas abiertas
- Hace falta numeracion correlativa por propietario?
- Se incluye desglose de alquiler, expensas y otros conceptos?
- Se puede anular un recibo si el pago estaba mal cargado?
